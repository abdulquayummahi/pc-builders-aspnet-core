\# PC Builders - E-Commerce Web Application



A full-stack e-commerce platform designed for purchasing PC hardware. Built with \*\*ASP.NET Core MVC\*\* and \*\*C#\*\*, this project demonstrates a clean N-Tier architecture, separating the application into Data Access (DAL), Business Logic (BLL), and Presentation (App) layers.



\## 🚀 Features



The application features a secure, session-based authentication system with dedicated portals for two distinct user roles:



\### Customer Portal

\* \*\*Browse Products:\*\* View a catalog of available PC parts with real-time stock levels and pricing.

\* \*\*Place Orders:\*\* Seamless one-click purchasing system.

\* \*\*Order History:\*\* A dedicated dashboard to view past purchases and track real-time order status (Pending, Shipped, Delivered).



\### Admin Portal

\* \*\*Inventory Management:\*\* Full CRUD operations to add, update, and delete products from the storefront.

\* \*\*Order Fulfillment:\*\* A comprehensive dashboard to view all customer orders and update shipping statuses dynamically.
